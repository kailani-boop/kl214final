# Hurricane Effects on Stream Chemistry

## Purpose of the Repository
This repository is meant to house all relevant data files and code that's used to recreate a graph from a given article. The repository is essential for storing the most recent versions of all the files and scripts, while staying organized. 

## What's Inside the Repository
Within the repository, there's a data file that includes all the raw data from the article. Additionally, it stores R files which are scripts that filter, select, and mutate the raw data to produce moving averages and graphs.  

## Accessing the Data
In the 'scratch.R' file, there's code to read the .csv data files in, as well as code that condenses the amount of data the user is working with. To access the raw data files, there's four .csv files within the data folder.
